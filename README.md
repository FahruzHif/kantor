# Kantor Kami

Website profil kantor sederhana menggunakan HTML, CSS, dan JavaScript murni.

## Struktur

- `index.html` — halaman utama (Beranda, Tentang, Layanan, Kontak)
- `style.css` — tampilan dan desain responsif
- `script.js` — menu mobile, tahun otomatis, dan form kontak

## Cara Menjalankan

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
python3 -m http.server 8000
```

Lalu buka http://localhost:8000.

## Menyesuaikan

Ganti nama kantor, alamat, telepon, email, dan deskripsi layanan di `index.html`.
Warna utama dapat diubah melalui variabel `--primary` di `style.css`.
